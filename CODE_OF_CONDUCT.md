# Code of Conduct

This is a small project run by one person. These are not house rules borrowed from a template; they are what I will actually do.

---

## The short version

**Criticise the work as hard as you like.** Tell me a feature is badly designed, an explanation is wrong, or a decision was a mistake. I would rather hear it than not. Nothing here is above criticism, including me.

**Leave people alone.** Harassment, personal attacks, slurs, and going after someone for who they are rather than what they said — none of that, anywhere this project reaches. Not in issues, not in pull requests, not in discussions.

**Assume the other person is trying.** Bug reports get written in a second language, at midnight, by someone frustrated. Read them generously.

---

## What I will do

If someone breaks this, I will delete the comment, lock the thread, or block the account — whichever fits. No warnings system, no appeals process, no committee. One person making a judgement call, which is all a project this size can honestly offer.

I will get it wrong occasionally. If you think I have, say so.

---

## Reporting

If someone is being abusive and I have not noticed, tell me on Discord: `flabbergastedindividual`.

GitHub also has its own reporting for harassment, and it works — their terms of service cover this regardless of what any file in any repository says. Use it if you would rather not come to me, or if the problem is me.

---

## Scope

Anywhere this project exists: issues, pull requests, discussions, and the website. It does not extend to what people do elsewhere, with the obvious exception — if someone uses another platform to harass a person because of something that happened here, that is still this project's problem.
